# scriptpysimple
# Mi Primer script de reconocimiento interactiva para kali linux #
Este es un proyecto **100% educativo** hecho para aprender las bases de la programacion python aplicada a la ciberseguridad.
## Que hace esta herramienta?
1. **Verifica  si un servidor esta vivo (Ping).
2. **Ver IP local:** Muestra las interfaces de red activas de nuestra maquina Kali.
3. **Salir** Libera la memoria del sistema y cierra el script de forma segura.
## Como funciona el codigo?
* **'while True' **Mantiene el programa de fondo de manera persistente.
* **'if/elif/else' (Tomando Desiciones):**compara la opcion del usuario para ver que bloque elegir
* **Manejo educativo de errores ('if resultado !=0')** Si un resultado no responde al ping. El programa analiza y te explica razones tecnicas.
